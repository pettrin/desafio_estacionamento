# Sistema de Estacionamento

Primeira versão do sistema!

## Estrutura de Pastas

```
index.html
README.md
assets/
  js/
    form.js
    listar.js
  img/
pages/
  estacionar.html
  listar.html
  remover.html
style/
  css/
    style.css
```

- Os dados dos veículos ficam salvos no storage do navegador (então cada um vê só o que cadastrou).
- Dá pra cadastrar e listar veículos.
- Tem um CSS básico só pra não ficar feio.
- O formulário de remover ainda não está pronto, vou terminar na próxima versão.
- Os arquivos JS ficam em `assets/js`.
- As imagens ficam em `assets/img`.
- O CSS principal está em `style/css/style.css`.
- As páginas HTML estão em `pages/`.

Para testar, é só abrir o `index.html` no navegador e usar as páginas.
